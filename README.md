# Sudoku

Jogo de Sudoku completo, bonito e totalmente funcional.

## ✨ Funcionalidades
- Geração automática de tabuleiros válidos
- Validação em tempo real das regras do Sudoku
- Sistema de dicas
- Interface moderna, limpa e totalmente responsiva
- Funciona perfeitamente no celular e desktop

## 🛠 Tecnologias
- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- JavaScript

## 🚀 Como rodar localmente

```bash
npm install
npm run dev

Acesse → http://localhost:3000
```
